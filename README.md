# Дело №0063: Какое прохождение S.T.A.L.K.E.R. правильное

Одностраничная фан-презентация в стиле терминала Зоны из S.T.A.L.K.E.R.: Shadow of Chernobyl.
Разбирает все 7 концовок игры и объясняет, какая из них — «настоящий» правильный финал.

## Что это

Статичный HTML-файл (`index.html`) без сборки и зависимостей — просто открывается в браузере.
Все стили и скрипт лежат в самом файле, картинки подключаются из папки `image/`.

## Структура страницы

1. **Gate (шлюз-модалка)** — экран инициализации с «загрузкой» терминала ZONE.OS перед показом сайта.
2. **Nav** — липкая шапка с навигацией по разделам и индикатором «Архив открыт».
3. **Hero** — заголовок дела и портрет Меченого.
4. **Ticker** — бегущая строка с фактами по делу.
5. **Досье** — статистика по концовкам (7 всего, 2 истинных, 5 ложных).
6. **Механика №1 / №2** — разбор двух переменных, влияющих на финал: деньги и репутация.
7. **Концовки** — карточки всех 7 финалов с условиями получения.
8. **Вердикт** — итоговая позиция архива с «за» и «против».
9. **Локации** — галерея секторов Зоны, ключевых для сюжета.
10. **Вопросы** — FAQ-аккордеон.
11. **Footer** — дисклеймер об отсутствии связи с правообладателем (GSC Game World).

## Нужные файлы изображений (папка `image/`)

- `hero-stalker.jpg` — портрет для hero-блока
- `mechanic-greed.jpg`, `mechanic-reputation.jpg` — фоновые иллюстрации механик
- `sector-01-kordon.jpg` … `sector-06-sarcofag.jpg` — 6 картинок галереи локаций
- `badge-compi.png`, `badge-raccoon.png` — мини-иконки для «проверено HR/Compliance»

Без этих файлов соответствующие блоки останутся с пустым/тёмным фоном — вёрстка не сломается.

## Технологии

- Чистый HTML/CSS/JS, без фреймворков
- Шрифты: Google Fonts — Oswald (заголовки), Rubik (текст), JetBrains Mono (терминальные надписи)
- Анимации на CSS `@keyframes`: скан-линии, шум/статика, глитч, свечение радиации, дрейфующие частицы, CRT-мерцание
- Уважает `prefers-reduced-motion`: все анимации гасятся почти до нуля, если у пользователя включена настройка «уменьшить движение»

## Кастомизация

Все ключевые цвета — CSS-переменные в `:root`:

```css
--bg, --bg-2, --panel, --panel-2   /* фоновые слои */
--rust, --rust-dim                 /* оранжевый акцент */
--toxic, --toxic-dim               /* токсично-зелёный акцент */
--violet                           /* фиолетовый акцент (аномалии) */
--ink, --ink-dim                   /* текст */
```

Поменяв эти переменные, можно перекрасить всю палитру, не трогая остальной CSS.

Текст самих концовок, вопросов FAQ и вердикта редактируется прямо в разметке
внутри секций `#концовки`, `#вопросы`, `#вердикт`.

## Известные ограничения

- Ссылки на изображения — относительные (`image/...`), при развёртывании держите структуру папок как есть.
- Gate-экран блокирует скролл (`html.locked`) до нажатия «Инициализировать» — это осознанное поведение, а не баг.
- Пасхалка для тех, кто заглянет в консоль браузера (см. `console.log` в конце скрипта).
